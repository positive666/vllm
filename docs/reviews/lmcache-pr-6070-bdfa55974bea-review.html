Failure mode

In eager mode, aborting after a STORE was scheduled may end its session while a worker’s final STORE is still outstanding. That STORE can recreate an already-retired session.

Compatible change

Extend the existing #6020 retirement rule to FINISHED_ABORTED only when an actual STORE or retained boundary block needs a completion report. Follow merged #5938 for delayed freeing. Use the existing rank aggregation and preserve lazy/no-work behavior.
