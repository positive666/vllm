Failure mode

An L2 writer can still read L1 bytes after the ordinary read TTL expires. A source eligible for deletion at that point may be recycled before the adapter replies.

Compatible change

Pin admitted STORE sources using a task-bound transfer identity. Release only the relevant pins after each terminal outcome. Close admission before draining pending stores. Apply upstream’s current store policy and manager selection.
